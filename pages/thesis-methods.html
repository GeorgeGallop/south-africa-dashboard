📚 Methods — The Mathematical Core

This page condenses the full mathematical formulations for the three pillars of the SAWEM evolutionary analysis framework. The system works as a closed loop: Agent-Based Model → Demand Scenario → OPF → Prices → Agent Learning (MDP) → next cycle.

1. Optimal Power Flow (OPF) — Security-Constrained Economic Dispatch

Objective — Minimise total system bid cost

min   Σt ∈ T Σg ∈ G [ Cg·pg,t + SUg·ug,t + NLg·vg,t ]

Subject to:

ConstraintEquationDual / Interpretation
Power balanceΣg pg,t + Σr pr,t = Dt + Σℓ fℓ,tλt = SMP (System Marginal Price)
Reserve requirementΣg rg,t ≥ Rtμt = reserve scarcity price
Unit output limitsvg,t·Pgmin ≤ pg,t ≤ vg,t·PgmaxKuhn-Tucker multipliers on capacity
Ramp constraintspg,t − pg,t−1 ≤ RUg   ;   pg,t−1 − pg,t ≤ RDginter-temporal coupling
Min up / min down(vg,t−1−vg,t)·(TUg,t − UTg) ≥ 0   ;   (vg,t−vg,t−1)·(TDg,t − DTg) ≥ 0unit commitment logic
DC line flowfℓ,t = (θn,t − θm,t)/Xℓ   ;   |fℓ,t| ≤ Fℓmaxζℓ,t+, ζℓ,t− = congestion rents
Reserve-energy couplingpg,t + rg,t ≤ vg,t·Pgmaxco-optimisation link
Lost opportunity paymentLOPg,t = (λt − Cg)·(pg,tunc − pg,tcon)compensation for constraint curtailment

Where: T = hours, G = generator set, Cg = bid price, pg,t = dispatch, SUg = start-up cost, NLg = no-load cost, vg,t ∈ {0,1} = commitment, ug,t ∈ {0,1} = start-up indicator, Dt = demand, fℓ,t = line flow, θ = voltage angle, Xℓ = line reactance, rg,t = reserve provision, Rt = reserve requirement. The optimisation is solved as a MILP using branch-and-cut. The SMP λt is the Lagrange multiplier on the power balance — this is the market-clearing price paid to all dispatched generators (pay-as-clear) and charged to all load. The dual variables on congestion constraints (ζ) produce locational marginal prices that differ by node when constraints bind.

ABM loop (per time-step):

  1. State: agents observe St = {SMP history, demand forecast, reserve margin, fuel prices, policy, congestion}
  2. Action: each agent chooses ai,t via policy πi(a|St)
  3. Aggregation: bids {Cg,t}, {Dtbid} collected by Market Operator
  4. OPF: SCUC/SCED runs → dispatch pg,t, SMP λt, congestion ζ, reserve prices
  5. Settlement: generator profit = λ·p − C(p) − SU − NL; load pays λ·D
  6. Learning: policies updated via MDP reward ri,t
  7. Evolution: demand growth, retirements, new entry, policy changes
  8. t → t+1
3. Markov Decision Processes (MDP) — Agent Learning over Time

Formal MDP: ⟨Si, Ai, Pi, Ri, γ⟩

ComponentMarket Instantiation
St{λt−τ..t, Dt, reserve margin, fuel prices, carbon tax, congestion, competitor capacities}

P(s′|s,a)driven by OPF outcome, competitor reactions, stochastic demand, outages
R(s,a)generator: λ·p − C(p) − SU − NL; load: −λ·D; IPP: Σ(strike−λ)·MWh − CAPEX
γ~0.95–0.99 (WACC 8–12% real)

Objective:

π* = argmax 𝓷[ Σ γτ R(St+τ, at+τ) ]

Q-learning update:

Q(S,a) ← Q(S,a) + α[R + γ maxa′ Q(S′,a′) − Q(S,a)]

For continuous actions: DDPG/PPO actor-critic.
