🤖 Agent-Based Modeling

Simulating complex, decentralized interactions of autonomous entities to discover emergent system-level behavior — a complete guide to the what, how, and why.

🧐 What Is Agent-Based Modeling?

Agent-Based Modeling (ABM) is a bottom-up computational modeling paradigm in which a system is represented as a collection of autonomous decision-making entities called agents. Each agent individually assesses its situation, makes decisions based on a set of rules or learned policies, and acts within a shared environment. The system-level outcomes — prices, grid reliability, emissions trajectories, market power — are not imposed from above but emerge from the decentralized interactions of these agents over time.

Why ABM for Electricity Markets?

Traditional power system models assume a central planner that minimizes total system cost, or a competitive equilibrium in which all participants are price-takers. Neither assumption holds in a real market — generators exercise market power, load aggregators hedge strategically, regulators intervene, and investors react to price signals with delays and bounded rationality. ABM captures all of this: strategic bidding, learning over time, policy feedback loops, and the messy reality of a transitioning market like SAWEM.

📚 Key contrast: Equilibrium models answer “What should happen if everyone is rational and informed?” ABM answers “What will happen given how real agents actually behave?”

📄 Core Components & Inputs

Every ABM requires five fundamental building blocks:

1. Agents

Autonomous entities with:

  • State — internal variables (cash, capacity, beliefs)
  • Perception — what they observe of the world
  • Decision rule — how they choose actions (hard-coded or learned)
  • Heterogeneity — agents differ in parameters, strategies, endowments
Example in SAWEM: each Eskom station is a distinct agent with its own heat rate, forced outage rate, coal stock, and vesting hedge position.
2. Environment

The shared space in which agents interact:

  • Spatial topology — transmission network with nodes, lines, impedances
  • Infrastructure — power plants, substations, pipelines, ports
  • Exogenous processes — weather, fuel prices, GDP growth
  • Institutions — market rules, price caps, carbon taxes
SAWEM environment: the Eskom transmission grid (nodes × lines), REIPPP auction calendar, carbon tax trajectory, NERSA price caps.
3. Interaction Rules

The “physics” and “economics” of agent interactions:

  • Bidding protocol — how offers become prices (pay-as-clear SMP)
  • Dispatch logic — OPF: min-cost security-constrained dispatch (MILP)
  • Settlement — who pays whom, when, and how much
  • Information flow — what agents observe about each other
In our framework: the OPF engine (SCUC/SCED) serves as the central interaction mechanism — every agent's bid is an input, SMP and dispatch are the output.
4. Initial Conditions

The starting state of every agent and the environment:

  • Existing fleet: capacity, age, fuel contracts, heat rates
  • Demand baseline: hourly load shapes by season and sector
  • Policy settings: carbon tax τ0, price cap, renewable target
  • Financial positions: Eskom debt, CPA legacy account, IPP PPA portfolio
Sourced from: Eskom Annual Reports, IRP2025, NERSA MYPD data, REIPPP bid windows 1–7.
5. Time Steps & Schedule

An ABM needs a scheduling protocol — the sequence in which agents act and the environment updates. Our SAWEM framework uses a dual-timescale architecture:

LayerResolutionWhat Happens Each Step
Power Market ABM Hourly (8,760 steps/yr) Agents submit bids → OPF clears → SMP, dispatch, congestion computed → agents learn from profit signals → next hour
Macro Economy ABM Annual (20–40 steps) Population × GDP × policy → demand growth → technology adoption (solar, EV) → industrial load change → Eskom corporate restructuring

The macro layer sets the demand scenario for the next 8,760 hours; the power layer aggregates its hourly outcomes into annual economic indicators (average SMP, volatility, emissions, affordability) that feed back into the macro agents' next annual state.

📜 The Math Under the Hood

ABM is not a single equation but a computational framework that weaves together several mathematical and algorithmic structures. Here is the full stack, from the individual agent up to emergent system properties.

3.1 Agent as a Stochastic Dynamical System

Each agent i is defined by a state-transition system:

Si,t+1 = fi( Si,t, ai,t, εi,t )   where ai,t = πi( Oi(St) )

3.2 The OPF Engine as the Interaction Mechanism

The bids from all power-market agents are collected and fed into the Security-Constrained Unit Commitment / Economic Dispatch (SCUC/SCED) optimization. This is a Mixed-Integer Linear Program (MILP):

Objective:
min   Σt Σg [ Cg · pg,t + SUg · ug,t + NLg · vg,t + VOLL · lst ]

Subject to:
Σg pg,t + lst = Dt   [λt = SMP]
vg,t · Pgmin ≤ pg,t ≤ vg,t · Pgmax
|fℓ,t| ≤ Fℓmax   [ζℓ, congestion rent]
pg,t − pg,t−1 ≤ RUg  ;   pg,t−1 − pg,t ≤ RDg
(vg,t−1 − vg,t) · (TUg,t − UTg) ≥ 0   (min up/down)

The dual variables (Lagrange multipliers) of this optimization are the economic signals that drive agent learning:

  • λt = System Marginal Price (SMP) — the market-clearing price for energy, equal to the marginal cost of the most expensive dispatched generator. Every generator receives λ for each MWh; every load pays λ.
  • ζℓ+, ζℓ− = congestion shadow prices on each line — these create locational marginal price (LMP) differentials between nodes.
  • μt = reserve scarcity price — the value of keeping one extra MW of reserve capacity.
3.3 Agent Learning via Markov Decision Processes

Agents are not static — they learn over time. Each agent faces a Markov Decision Process (MDP) defined by the tuple ⟨S, A, P, R, γ⟩:

Vπ(s) = 𝓷[ Στ=0∞ γτ · R(st+τ, at+τ) | s0 = s, π ]

Q-Learning (discrete actions):

Q(s, a) ← Q(s, a) + α[ R + γ maxa' Q(s', a') − Q(s, a) ]

Deep Deterministic Policy Gradient (DDPG) (continuous actions — e.g., bid price is a real number):

∇θμ J ≈ 𝓷[ ∇a Q(s, a | θQ) · ∇θμ μ(s | θμ) ]

Multi-Agent DDPG (MADDPG) — each generator learns its bid policy while accounting for other agents' actions (the market is non-stationary from any single agent's perspective):

∇θi J(μi) = 𝓷[ ∇θi μi(ai | s) · ∇ai Qiμ (s, a1, ..., aN) |ai = μi(s) ]

The MADDPG critic Qi receives the actions of all agents at the central critic, stabilising learning in the non-stationary multi-agent environment. Each agent's reward is its profit:

Rg,t = λt · pg,t − [ fuel_cost(g) + O&M(g) + startup_cost(g) + no_load_cost(g) ]
3.4 Aggregation — From Micro to Macro

System-level quantities are summations over agents or statistics of the distribution of agent states:

Total generation:   Gt = Σg ∈ G pg,t
Average SMP (load-weighted):   ¯λyr = (Σh λh · Dh) / (Σh Dh)
Herfindahl-Hirschman Index (market concentration):   HHI = Σg (shareg)2
Emissions:   CO₂t = Σg pg,t · heat_rateg · emission_factorg
Affordability:   bill_sharehh = (Σh λh · Dhh,h) / household_incomehh

📊 Outputs — What Data the Model Produces

A single simulation run generates a rich, multi-level dataset. The key outputs fall into three categories:

Level 1: Agent Trajectories

Every agent's state and actions over every time step:

  • Hourly dispatch pg,t per generator
  • Hourly bid curves {Pk, Ck} per generator
  • Profit & loss time series per agent
  • Maintenance schedules, retirement flags
  • Load agent demand bids Dtbid
  • IPP investment decisions (MW, technology, year)
  • Learning curves: Q-values, policy parameters over time
Level 2: System-Level Time Series

Aggregate market outcomes at hourly to annual resolution:

  • Hourly SMP & LMP at every node
  • Line flows & congestion rents per constraint
  • Reserve prices & scarcity events
  • Unserved energy (MWh lost) & LOLP
  • Total system cost (fuel + O&M + start-up + unserved)
  • CO₂ emissions hourly, daily, annual
  • Renewable curtailment (MWh & % of potential)
  • Market concentration (HHI) over time
Level 3: Emergent Metrics

Higher-level patterns computed from trajectory analysis:

  • Phase transitions: the year coal-baseload collapses below 50% of energy share
  • Price duration curves: hours/yr that SMP exceeds thresholds (e.g., R2000/MWh)
  • Learning convergence: do generator bid strategies stabilise, oscillate, or diverge?
  • Market power indices: Lerner index L = (SMP − SRMC) / SMP per generator-hour
  • System resilience: hours of unserved energy under N-1 vs N-2 contingencies
  • Affordability frontier: combinations of renewable share vs average SMP vs bill-as-%income
  • Technology transition S-curves: coal → gas → renewables + storage adoption rates
Data Formats

Outputs are stored as multi-index DataFrames (agent, time, variable) for Level 1, time-indexed arrays for Level 2, and scalar/dictionary summaries for Level 3. Typical a 20-year run produces:

  • ~175,200 OPF solutions (20 yr × 8,760 hr/yr)
  • ~50–200 GB of raw time-series data (before downsampling)
  • ~50–200 emergent metrics summarised per scenario

🔎 What You Can Infer from Agent Behavior Over Time

The real power of ABM is not in the raw data but in what you can infer by analyzing how agent behavior evolves. Here is what to look for:

🔬 1. Identifying Emergent Phenomena

The most important insight from any ABM is emergence: system-level patterns that are not explicitly programmed and cannot be predicted by studying agents individually. In the SAWEM ABM, watch for:

  • Merit-order effect: as renewable penetration rises, average SMP drops and price volatility increases — no central planner instructed this, it emerges from the dispatch stack.
  • Strategic withholding cycles: generators learn to coordinate (tacitly) by taking turns withholding capacity, creating price spikes that are higher than any individual agent's market power would suggest.
  • Investment waves: agents delay investment until SMP is high enough, then all build at once — creating boom-bust capacity cycles.
  • Basin of attraction shifts: under high carbon tax + fast RE buildout, the system may cross a threshold where coal becomes uneconomic even before its design life — a “stranded asset” phase transition.
📖 2. Counterfactual & Policy Analysis

Run the same model with one parameter changed and compare the emergent outcomes:

  • Without vesting hedge: does Eskom Gen exercise full market power? What is the SMP uplift compared to the baseline with the hedge in place?
  • Higher carbon tax (R500/tCO₂): does coal retire faster? By how much? Does gas fill the gap, or does unserved energy increase?
  • Faster transmission expansion: does congestion in the Cape corridor disappear? Do Northern Cape wind/solar projects get built sooner?
  • No LNG import terminal: is gas development constrained? Does coal run longer? What is the cost of this constraint?
📈 3. Causal Mechanism Discovery

Agent trajectories allow you to trace causal chains that are invisible in equilibrium models:

  • Why did SMP spike in Year 7? Trace back: high coal price → old stations reduced output → reserve margin dropped → gas agents raised bids (scarcity pricing) → SMP hit R4000/MWh. Which link was most important?
  • Why did solar adoption plateau? Households in deciles 3–5 hit capital constraints → adoption S-curve saturated at 40% → mid-day demand remains high → duck curve less severe than feared.
  • Eskom debt spiral: low SMP → Eskom Gen revenue falls → debt service > cash flow → Treasury must bail out → fiscal pressure → carbon tax rise delayed → emissions higher →…
Statistical tools used: Granger causality tests on agent action time series; Shapley values for feature importance in agent policy networks; do-calculus for intervention analysis (P(Y | do(X))).
📜 4. Sensitivity & Robustness Analysis

Which assumptions drive the results, and which are harmless?

  • One-factor-at-a-time (OAT): perturb fuel price, demand growth, carbon tax, learning rate, outage probability — each by ±10% — and measure the effect on SMP, emissions, and unserved energy.
  • Multi-factor Morris screening: identify the 3–5 parameters that explain >90% of output variance.
  • Monte Carlo ensembles: run 100+ simulations with random parameter draws and build confidence intervals on key metrics.
  • Scenario discovery: which combinations of input parameters lead to “bad” outcomes (e.g., unserved energy >500 GWh/yr)? Use classification trees on the ensemble to map the “danger zone.”
⚠️ Important caveat: ABM outputs are conditional on the decision rules you program. If agents do not learn to exercise market power, the model will overestimate competition. Always validate against real-world market outcomes before using results for policy.
5. Policy & Strategic Recommendations

The ultimate inference from the SAWEM ABM is actionable. The model can answer:

  • “How much vesting hedge is needed to prevent market abuse during the transition?” — run the model with 0%, 25%, 50%, 75%, 100% hedge decay and observe the SMP uplift.
  • “Will the JET P funding arrive fast enough to avoid a gas-lock-in?” — compare JET Fast vs JET Slow vs No JET scenarios for emissions and cost.
  • “Which transmission corridors are the highest-value first investments?” — the model identifies constraints with the highest annual congestion rent, which is the social value of relieving them.
  • “Is Eskom Gen commercially viable after unbundling?” — simulate the revenue stream of the Genco under different hedge structures and retirement schedules; if expected NPV < 0, privatization is unlikely without a capacity payment mechanism.
