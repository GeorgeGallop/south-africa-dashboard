How the change gets into the dashboard

1. Edit here

The tree below is the live dashboard sidebar. Add a section, move a page into another section, reorder, rename or delete.

2. Save to dashboard

One click writes the new tree into the project: js/sidebar-layout.js and the sidebar in index.html. No file dialog.

3. Open Home

Go back to the dashboard home page. The sidebar there is already the layout you saved.

The dashboard server on port 3101 has to be running (py server.py) so Save can write the files. Live Server on 5500 still shows Home afterwards.
